# 雨宮 眠夢(ねむ) 個人サイト

## ファイルの構成

| ファイル | 役割 | 触る？ |
|---|---|---|
| `js/site-config.js` | 名前・自己紹介・リンク・最新おすすめなど、**中身のすべて** | よく触る |
| `index.html` | ページの骨組み。タイトルと共有時の表示(OGP)だけ書き換える | たまに |
| `css/style.css` | 見た目。いちばん上の色や幅の値だけ変えれば全体に反映 | たまに |
| `js/main.js` | 画面を組み立てるプログラム | 触らない |
| `assets/` | 画像置き場(`icon.svg` は仮のアイコン) | 画像を入れる |

## よくある更新

- **最新・おすすめを変える**: `site-config.js` の `featured` の中のカードを書き換えます。YouTubeの動画URLを書くと、サムネイルが自動で出ます。
- **自己紹介動画を出す**: `media.list` のYouTubeの `player.video` に、動画のURLを書きます。
- **媒体を増やす**: `media.list` に1つぶん足します(BOOTHの例がコメントで入っています)。上にあるものほど上に表示されます。
- **アイコンを変える**: `assets/` に画像を入れて、`profile.icon` のパスを書き換えます。
- **イメージカラーを変える**: `theme.color` を書き換えます。明るめの色にしてください(文字は濃い紺で載せます)。

## 公開のしかた(GitHubから自動公開)

1. このフォルダの中身をGitHubのリポジトリにアップします(`index.html` が一番上の階層に来るように)。
2. GitHub Pages、Cloudflare Pages、Netlify などで、そのリポジトリを公開します。
3. 独自ドメインを使う場合は、公開サービスの設定でドメインをつなぎます。
4. **QR名刺は、最終的なURLが決まってから作ります。**

## ローカルで確認する

`index.html` をダブルクリックでも開けます。YouTubeの動画は、公開したURL(`https://`)の上で試すのが確実です。
